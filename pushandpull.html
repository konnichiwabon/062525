🚀 Step-by-Step GitHub Push & Pull Guide

📤 1. Push Files to GitHub

Step 1: Initialize Git

cd your-project-folder
git init

Step 2: Link your GitHub repo

git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

Step 3: Add your files

git add .

Step 4: Commit your changes

git commit -m "Initial commit"

Step 5: Push to GitHub

git push -u origin master

💡 Use main instead of master if that’s your default branch:

git push -u origin main

📥 2. Pull Files from GitHub

git pull origin main

📦 3. Clone a GitHub Repo

git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

🛠️ FOR OVERRIDING

Use the following commands to override your local code with the latest version from GitHub (⚠️ this will delete local changes):

git fetch origin
git reset --hard origin/main
